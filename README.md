# 🛡️ GG // Identity Security Auditor

Aplicativo de segurança defensiva com interface web em português e funcionamento inicial em ambiente de demonstração.

🌐 **[Abrir interface web](https://geovanniandrade.github.io/gg-identity-security-auditor/)**

## Como funciona
- Utilize o formulário ou importe um arquivo de teste para executar a análise compatível com esta primeira versão.
- Confira os resultados e suas limitações; informações insuficientes não comprovam vulnerabilidades.
- Gere um PDF pela opção de impressão do navegador.

## Segurança e escopo
O protótipo processa dados localmente no navegador, sem backend. **Não está homologado para uso em produção.** Utilize somente dados fictícios ou autorizados; não publique informações corporativas confidenciais.
