🧭 Como começar

🧪 Demonstração: clique em Carregar exemplo fictício. Não requer domínio AD.

🧭 Assistente de coleta do Active Directory

Preencha os dados do ambiente. O site não consulta o AD: ele apenas monta um comando local, somente leitura, que você poderá revisar antes de executar.

Não sabe o domínio? Copie o comando abaixo no PowerShell e use o resultado nesse campo.

(Get-ADDomain).DNSRoot

Exemplo ilustrativo: empresa.local. É necessário o módulo ActiveDirectory.

Para descobrir as OUs disponíveis, execute o comando abaixo e copie o DistinguishedName completo da OU autorizada.

Get-ADOrganizationalUnit -Filter * | Select Name, DistinguishedName

Se escolher domínio inteiro, a coleta abrangerá as contas de todas as OUs deste domínio, dentro das permissões de leitura.

A exportação inclui identificadores e atributos de contas. Use apenas escopo autorizado. Não publique o CSV nem o PDF com dados reais.

📋 Comandos prontos

Revise o script antes de colar no console. Campo IsAdmin ficará vazio (não avaliado). Se um comando falhar, não tente contornar políticas corporativas.

Requer módulo ActiveDirectory e permissão de consulta. Não contorne políticas de execução. O arquivo exportado contém nomes de contas: mantenha-o em local restrito e não publique no GitHub.
